# Pasing Drive

Open-World-Fahrspiel in München-Pasing mit dem Roadster aus F1Racing.

Spielen: https://robo7722.github.io/PasingDrive/

- Karte: OpenStreetMap-Daten (© OpenStreetMap-Mitwirkende, ODbL), erzeugt mit `tools/build_map.py` aus einem Overpass-Export
- Gebäude mit Höhen/Dachformen aus OSM, Straßen, Bahn, Würm, Parks, Bäume
- Startpunkt frei auf der Karte wählbar
